Features

Everything a serious player needs. Nothing it doesn't.

Vox-like shell

A compact, elegant window that stays out of the way. Floating window options and a tray icon keep it unobtrusive while you work.

Custom-ize everything

10 themed variants, any accent color, layouts and transparency options. Make the player look the way you like — the accent you pick here previews it.

Buttery crossfade

Up to 15 seconds of seamless crossfade between tracks, with dual-deck Web Audio timing so transitions feel engineered, not abrupt.

Audio-reactive visualizer

The analyser reads the real rendered signal — not a synthetic waveform — so the bars genuinely dance to what you hear.

Pop-out now playing

An always-on-top mini window mirrors the current track with artwork and transport. Dock it anywhere; it never shows a blank frame.

Playlists in two clicks

Add any track or SoundCloud result straight into a playlist from the row you're looking at — no drag-and-drop shuffle required.

Local library

Scan folders, play FLAC / WAV / MP3 / M4A and more, with automatic artwork from embedded tags. Your library stays on your disk.

HD output pipeline

Choose Auto, 44.1, 48, 96 or 192 kHz with a rebuilt graph — no Windows resampler in the path, and a native WASAPI mode is on the roadmap.

Media keys & tray

Play/pause/next/previous keys, a tray menu, and a 10-band EQ you can dial from the settings drawer while a track keeps playing.

SoundCloud

Stream the cloud. Take it offline.

Search SoundCloud, browse the trending chart or paste any link — tracks stream straight into your library and behave exactly like local files: crossfade, visualizer, playlists, queue, pop-out.

  • Search, trending chart & quick genre chips
  • Paste a track or set URL — it resolves instantly
  • One-click offline download to your chosen folder
  • Downloaded tracks replace their stream entry — playlists survive

Honest note: SoundCloud issues no official API keys, so Equip uses the same public unauthenticated client the web app does. It's a gray area — replaceable from Settings if SoundCloud rotates it. Public streams are 128 kbps MP3.

Audio engine

State-of-the-art output, honest sources.

Equip rebuilds its Web Audio graph whenever you change output rate — Auto, 44.1, 48, 96 or 192 kHz — with a 10-band EQ and master gain applied in the same graph. The visualizer reads the analyser at the very end of that chain.

Auto44.1 kHz48 kHz96 kHz192 kHz

It can't add bits the source never had: SoundCloud's public tier is 128 kbps MP3, and downloads match that quality. Local files play at whatever quality they are.
